# Dependencias de Python del proyecto.
# Se instalan todas juntas con:  pip install -r requirements.txt
#
# Flask              -> el framework web (rutas, plantillas, sesiones).
# Flask-SQLAlchemy   -> integra SQLAlchemy (el ORM) con Flask.

#                       de entorno (así la contraseña no queda escrita en el código).
# Flask-Login        -> maneja la sesión: quién inició sesión, login/logout,
#                       y bloquea páginas a quien no entró.          (paso 0.2)
# Flask-WTF          -> formularios con validación y protección CSRF.  (paso 0.2)
# email-validator    -> lo usa Flask-WTF para validar direcciones de email.
